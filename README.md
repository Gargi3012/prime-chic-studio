# Prime Outlet — Luxury Multibrand Flagship Store

A high-converting, mobile-first luxury fashion web application for **Prime Outlet** — a premier clothing, footwear, and accessories destination located in Ganaur, Sonipat, Haryana.

Designed with quiet luxury editorial aesthetics inspired by Farfetch, Nykaa Luxe, and Zara Studio.

---

## ✦ Key Features

- **Panoramic Editorial Hero**: Wide landscape campaign showcase featuring male & female luxury resort styling with quick-action CTAs.
- **Hot & Happening Drops**: Postage-stamp perforated category cards with parchment ribbons and verified markdown callouts.
- **The Prime Deck Showcase**: 3D interactive fanned deck featuring bespoke runway tailoring, luxury dresses, and street fits.
- **Smart Category Sync**: Real-time multi-department filter for Men, Women, and Kids with dedicated high-res photography.
- **AI Stylist & Outfit Builder**: Interactive fit recommendations and customized wardrobe curation.
- **Instant WhatsApp Concierge**: 1-click VIP order booking and size reservation directly with the flagship store team.

---

## 🛠️ Tech Stack

- **Framework**: TanStack Start / React 19 / Vite
- **Styling**: Tailwind CSS v4 & Vanilla CSS Custom Tokens
- **Animations**: Framer Motion & Lucide Icons
- **Deployment**: Nitro & Edge-ready Cloudflare/Vercel worker

## 🚀 Getting Started

### Prerequisites
- [Bun](https://bun.sh/) or Node.js (v20+)

### Installation & Run Locally

```bash
# Clone the repository
git clone https://github.com/Gargi3012/prime-chic-studio.git

# Navigate into the project folder
cd prime-chic-studio

# Install dependencies
bun install

# Start the local development server
bun run dev
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
